# pwm-showcase — 자산 대시보드 체험판

- **무엇**: 개인 자산 대시보드(자산·텐배거·예측 세 화면)를 그대로 옮긴 정적 사이트입니다. 숫자·종목·문장은 전부 가짜이고 총액은 ₩1,000만 고정입니다.
- **다시 만들기**: 사무실 맥(Tailscale 안)에서 `python3 build/make_demo.py` 한 줄 — 원본을 복사하고 `data/` 를 새로 만든 뒤 실명 검사(`build/check.py`)까지 합니다.
- **주소**: https://happydyoon.github.io/pwm-showcase/
